Análise da Frota de Ônibus de SP

Pipeline de dados que coleta sozinho, de hora em hora, quantos ônibus estão rodando em cada uma das mais de 1.000 linhas de São Paulo pela API Olho Vivo da SPTrans. Como a API só mostra o "agora", o projeto guarda o histórico e mostra num dashboard o horário de pico da frota, a diferença entre dias úteis e fins de semana e o ranking das linhas.

A coleta roda no GitHub Actions, sem depender de nenhum computador ligado, com o token da API guardado como segredo do repositório. O dashboard em Streamlit atualiza sozinho conforme o histórico cresce e permite buscar uma linha pelo nome do bairro ou terminal.

Full Stack · Projeto pessoal

Banco Multimoedas

Sistema bancário web: o usuário deposita em reais convertendo para dólar, euro ou libra, consulta saldos, faz saques e vê o extrato, tudo atualizado na hora sem recarregar a página. A página conversa com uma API própria em Flask, e os dados ficam salvos no PostgreSQL.

Comecei como programa de terminal e evoluí para web reaproveitando toda a camada de banco de dados. Tem cadastro e login com senhas protegidas por hash, e cada usuário só acessa a própria conta, porque a API identifica quem está logado pela sessão. Publicado no Render, com o banco no Neon.

Análise de Câmbio

Coleta automatizada de 11 anos de cotações do dólar, euro, libra e iene pela API do Banco Central, com tratamento, análise exploratória e um dashboard interativo publicado para responder quatro perguntas sobre o câmbio no Brasil.

Mostrei que o dólar dobrou desde 2015, medi a alta de 32% na pandemia e validei os dados, descartando uma série incorreta da fonte.
