Full Stack · Projeto pessoal

Banco Multimoedas

Sistema bancário web: o usuário deposita em reais convertendo para dólar, euro ou libra, consulta saldos, faz saques e vê o extrato, tudo atualizado na hora sem recarregar a página. A página conversa com uma API própria em Flask, e os dados ficam salvos no PostgreSQL.

Comecei como programa de terminal e evoluí para web reaproveitando toda a camada de banco de dados. A API tem 6 rotas (GET e POST) com validação e senhas guardadas com hash.

Análise de Câmbio

Coleta automatizada de 11 anos de cotações do dólar, euro, libra e iene pela API do Banco Central, com tratamento, análise exploratória e um dashboard interativo publicado para responder quatro perguntas sobre o câmbio no Brasil.

Mostrei que o dólar dobrou desde 2015, medi a alta de 32% na pandemia e validei os dados, descartando uma série incorreta da fonte.
